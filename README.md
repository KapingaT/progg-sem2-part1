# RaceDay.P1

## System Description

RaceDay is a race management system designed to manage race events, user accounts, organisers, participants, event categories, enrolments, and race results.

The system allows users to create and manage an account. Each account is linked to a specific role within the system: either an Organiser or a Participant. These roles have different responsibilities and permissions within the RaceDay system.

Organisers are responsible for creating and managing race events, while participants can browse available events, select categories, enrol in races, and track their personal results.

## Users and Accounts

The RaceDay system consists of users and accounts.

In order to access the system, a user must have an account. When creating an account, the user will be assigned one of the two available roles:

* Organiser
* Participant

Each role has specific activities and permissions within the system.

## Roles

### Organiser

Organisers are responsible for managing and organising race events within the system.

Their responsibilities include:

* Creating race events.
* Managing existing race events.
* Creating and managing event categories.
* Viewing all participant enrolments.
* Capturing and managing participant race results.

### Participant

Participants are users who take part in race events.

Their responsibilities include:

* Browsing available race events.
* Viewing and selecting event categories.
* Enrolling in race events.
* Tracking their personal race participation.
* Viewing their personal race results.
