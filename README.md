# RaceDay.P1

## System Description

RaceDay is a race management system that allows organisers and participants to manage race events, categories, enrolments, and results.

Users must create an account and are assigned either an Organiser or Participant role.

## Roles

### Organiser

Organisers can:

* Create and manage events.
* Manage event categories.
* View participant enrolments.
* Capture participant results.

### Participant

Participants can:
* Browse available events.
* Select event categories.
* Enrol in events.
* Track and view their personal results.
